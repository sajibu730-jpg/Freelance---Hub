Owner Security

Authenticator MFA · Recovery Codes · Trusted Browser Inventory

Important protection rule

TOTP MFA is the primary second factor. Recovery codes are one-time emergency codes. Registering a browser is an inventory record only; it does not make a device a login factor or automatically block stolen sessions.

1 · Authenticator App (TOTP)

Checking MFA status…

Scan this QR code with Google Authenticator, Microsoft Authenticator, or another TOTP app. Keep the secret private.

2 · Recovery Codes

Generate only after MFA is verified. Each code works once. New codes retire the previous unused set.

Checking recovery codes…

Save them offline, not in screenshots or shared chats. They are shown only once.

3 · Trusted Browsers

Register this browser after MFA verification. This is a device inventory, not hardware-backed authentication.

4 · Emergency Recovery

If the old authenticator or phone is lost, sign in to the Owner account on a new device and use one unused recovery code. This retires all recovery codes, revokes registered browsers, and signs out all active sessions. Then sign in again, enroll a new authenticator, and generate fresh codes.
